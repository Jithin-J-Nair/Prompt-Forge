# Expertise composition (SkillForge knowledge)

Version: 1.0.0

## What composition means

SkillForge turns a brief + category into:

1. A skill graph (who thinks)
2. Project DNA (what we believe and what is unknown)
3. Blueprints (how to build / decide)
4. An agent handoff pack (instructions only)

## What composition is not

- Not a finished website or product binary
- Not a chatbot conversation
- Not authorization to execute tools

## Quality bar

Accepted packages must be craft-dense enough that an external agent can act without inventing a new concept. Empty binders with gold stamps fail Review Council.
