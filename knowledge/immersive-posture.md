# Immersive posture pack (Site-of-the-Year bar)

Version: 1.0.0  
Usage: Injected into COOK reference principles for immersive categories. Transferable craft — never a clone brief.

## Posture cards

1. **World-as-product** — The experience canvas is the product. DOM chrome is scaffolding.
2. **One composition** — First viewport = brand + one headline + one line + one CTA group + one full-bleed visual.
3. **Owned motion** — Every animated property has one owner (GSAP / R3F / shader). Fighting timelines fail craft.
4. **Silence is craft** — 2–5 signature beats; noise on every scroll tick is amateur.
5. **Motif recurrence** — Nouns from the brief return in type, material, caption, and shader accent.
6. **Fail soft** — WebGL unavailable → static filmstrip + captions still tell the story.
7. **Invite after proof** — CTA lands after craft belief, not wallpapered on every chapter.

## Anti-experience gallery (never ship)

| Anti-pattern | Why it fails SOTY |
|---|---|
| Card-grid hero | Reads as SaaS marketing, not a world |
| Purple glow / cream+terracotta AI defaults | Instant “generated” look |
| Eager GLTF dump on first paint | Jank; no authored arrival |
| Floating promo chips / stat strips | Clutter kills composition |
| Cloning Active Theory / studio layouts | Theft, not craft |
| Feature-band scroll with GSAP lipstick | Motion without story |

## Active Theory–class transferable principles

- Immersive world first; UI almost invisible.
- Technical spectacle serves narrative clarity — not demo-reel noise.
- Chapter pacing feels scored; interaction teaches world rules.
- Reference = energy/pacing/craft bar only.
