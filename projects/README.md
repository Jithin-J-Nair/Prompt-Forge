# Project records and Project DNA

Projects are tenant-owned and contain immutable revisions. Each composition run pins one project revision. Project DNA covers Vision, User, Problem, Market, Differentiation, Business Model, Core Features, User Flows, Technical Stack, Architecture, Success Metrics, Risk Analysis, and Roadmap; distinguish confirmed, inferred, unknown, and not-applicable values with provenance.

Contract validation artifacts:

- [`project-dna.schema.json`](project-dna.schema.json) — versioned Project DNA schema.
- [`fixtures/`](fixtures/) — curated example and negative DNA fixtures (not production data).
