# Review Council boundary

The mandatory council is Creative Director, Product Strategist, Systems Architect, Performance Engineer, Security Engineer, UX Architect, Accessibility Reviewer, and Awwwards Reviewer. Assessments are versioned, evidence-backed, artifact-specific, and cannot be silently overridden. Proposed gate defaults and bounded revision behavior are documented in the [review policy](../docs/SKILLFORGE_ARCHITECTURE.md#review-council-and-revision-loop).
