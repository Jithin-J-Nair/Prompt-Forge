## CRITICAL: HOW TO BUILD “INSANE GITHUB-LEVEL SKILLS” WITHOUT STEALING REPOS

1. **Survey** publicly known high-practice skill ecosystems and agent-skill patterns (Cursor/Claude-style skill packs, awesome-lists, famous engineering playbooks, WebGL/motion studio craft norms). Use them as **inspiration for structure and rigor**, not as copy-paste sources.

3. Record provenance as: `SkillForge curated distillation vX` + knowledge notes — never “copied from repo X”.
