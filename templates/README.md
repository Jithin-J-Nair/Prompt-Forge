# Versioned templates

Templates define an artifact logical key/type, schema version, required sections, variables, rendering constraints, and validation rules. Published templates are immutable; updates publish a new version. Render structured data before Markdown/export formats, escape untrusted values, and retain template identity/version and output hash with each artifact.
